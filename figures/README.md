# Figures

This directory contains publication-quality figures (300 DPI PNG) generated by
`src/visualization/roc_shap.py`.

## Regenerate Figures

```bash
# First train models
python src/data/generate_synthetic.py
python src/train/trainer.py

# Then generate figures
python src/visualization/roc_shap.py
```

## Expected Output

| File | Description | Paper Reference |
|---|---|---|
| `roc_curves.png` | ROC curves for all 5 classifiers on held-out test set (W21–S24) | Figure 1 |
| `shap_importance.png` | SHAP global feature importance — Top 10 features, XGBoost | Figure 2 |

## Figure Descriptions

### Figure 1: ROC Curves
- X-axis: False Positive Rate
- Y-axis: True Positive Rate
- 5 curves: XGBoost (AUC=0.91), Random Forest (0.88), MLP (0.86), SVM (0.83), Logistic (0.74)
- Champion model (XGBoost) shown as solid blue line; others dashed

### Figure 2: SHAP Global Feature Importance
- Horizontal bar chart, top 10 features by Mean |SHAP| value
- Colour-coded by importance tier (dark blue ≥ 0.12, medium ≥ 0.07, light < 0.07)
- Key finding: `num_funding_rounds` (0.187) and `batch_year_encoded` (0.163) dominate;
  `faang_experience` near-zero (0.031) — elite pedigree alone does not predict success
