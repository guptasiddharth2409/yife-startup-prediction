# Figures

All figures are **auto-generated** by the pipeline. Run the following to populate this directory:

```bash
python src/evaluate.py
python src/shap_analysis.py
```

or simply:

```bash
python src/run_pipeline.py
```

---

## Expected Output Files

| File | Generated by | Description |
|------|-------------|-------------|
| `roc_curves.png` | `evaluate.py` | Overlaid ROC curves for all 5 models |
| `confusion_matrices.png` | `evaluate.py` | 2×3 confusion matrix grid |
| `metrics_table.csv` | `evaluate.py` | Precision / Recall / F1 / AUROC table |
| `shap_bar.png` | `shap_analysis.py` | Mean |SHAP| bar chart (XGBoost) |
| `shap_beeswarm.png` | `shap_analysis.py` | SHAP beeswarm summary plot |
