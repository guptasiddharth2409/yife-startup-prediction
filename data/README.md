# Data Directory

## Structure

```
data/
├── raw/
│   ├── sample_yc_data.csv       ← START HERE: 100 real YC companies, manually curated
│   ├── yc_companies.csv         ← Full Kaggle dataset (download separately)
│   ├── crunchbase_yc.csv        ← Crunchbase export (requires API access)
│   └── founders_github.parquet  ← Generated by src/data/collect_github.py
└── processed/
    └── yife_features.parquet    ← Generated by pipeline
```

## Quick Start with Sample Data

The `sample_yc_data.csv` contains **100 real YC-funded companies** (W03–W23) manually
curated from the public YC company directory. This is enough to run the full pipeline:

```bash
python src/data/generate_synthetic.py   # generates full 4,323-row dataset
python src/train/trainer.py             # trains all 5 models
python src/visualization/roc_shap.py   # generates figures
```

## Full Dataset (for exact paper reproduction)

| Source | How to Obtain | Place At |
|---|---|---|
| YC Company Directory | [Kaggle](https://www.kaggle.com/datasets/dylanknasir/y-combinator-companies) | `data/raw/yc_companies.csv` |
| Crunchbase Funding | [Crunchbase Free Tier](https://data.crunchbase.com) | `data/raw/crunchbase_yc.csv` |
| GitHub Founder Stats | Run `src/data/collect_github.py` | Auto-generated |

## Feature Definitions (YIFE 14 Features)

| Feature | Type | Description | Source |
|---|---|---|---|
| `total_funding_usd` | Continuous | Total capital raised (USD) | Crunchbase |
| `num_funding_rounds` | Integer | Number of distinct funding events | Crunchbase |
| `seed_round_size` | Continuous | Seed round amount (USD) | Crunchbase |
| `team_size` | Integer | Number of co-founders at application | YC Directory |
| `faang_experience` | Binary | Any founder had prior FAANG role | LinkedIn |
| `elite_edu` | Binary | Any founder attended Top-20 university | LinkedIn |
| `github_repo_count` | Integer | Total public repos of founding team | GitHub API |
| `github_commit_freq` | Continuous | Avg. weekly commits (6 months pre-YC) | GitHub API |
| `batch_year_encoded` | Ordinal | Encoded batch year | YC Directory |
| `batch_size` | Integer | Number of companies in same YC batch | YC Directory |
| `industry_category` | Categorical | YC-assigned category | YC Directory |
| `ai_flag` | Binary | AI as core product component | Manual annotation |
| `geo_cluster` | Categorical | Encoded location cluster | YC Directory |
| `tier1_vc_investor` | Binary | Backed by Tier-1 VC post-YC | Crunchbase |

## Success Label Definition (Section 3.2)

A company is labeled **success=1** if it meets ≥1 of the following criteria
(evaluated as of January 2024):
- Raised a Series A or beyond
- Acquired at exit valuation ≥ $10M
- IPO / SPAC listing
- Active operations with revenue > $1M ARR (where publicly verifiable)

Overall success rate in full dataset: **45.3%** (1,958 / 4,323 companies).
