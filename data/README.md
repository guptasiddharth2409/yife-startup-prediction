# Data Directory

This directory documents the data required by the YIFE pipeline. The original research dataset is **not redistributed** here.

## Structure

```text
data/
├── raw/
│   ├── sample_yc_data.csv       # Small public sample for demonstration
│   ├── yc_companies.*            # User-provided YC/Kaggle source data
│   ├── crunchbase_yc.*           # User-provided Crunchbase export
│   └── founders_github.*         # Founder GitHub metrics generated by the collector
└── processed/
    └── yife_features.parquet     # Generated processed feature table
```

## Research Data Sources

The published study constructed the curated dataset from multiple complementary sources:

| Source | Research variables | Availability in repo |
|---|---|---|
| YC Company Directory / Kaggle | Batch, category, status, team size, location | Not redistributed; obtain from the original source |
| Crunchbase | Funding rounds, total funding, lead-investor information | Not redistributed; requires appropriate access |
| GitHub Public API | Public repositories and commit activity for sampled founders | Can be regenerated with the collector |
| LinkedIn manual sample | Education and prior-employer information for 500 founder profiles | Manual research sample; not redistributed |

The final curated research dataset contains **4,323 YC-funded companies from W05 through S24 (2005–2024)**. Companies without publicly verifiable outcome data were excluded from the labeled set.

## Synthetic Data

For users who do not have access to the original research inputs, the repository provides a deterministic synthetic-data generator:

```bash
python src/data/generate_synthetic.py
```

It creates `data/processed/yife_features.parquet` with 4,323 synthetic records and the documented YIFE schema.

**Important:** the synthetic data are a **pipeline and software demonstration aid**. They are not the original research records, are not a byte-for-byte replacement for the research dataset, and should not be used to claim reproduction of the published test metrics.

## Success Label Definition

The published study labels a company successful if it satisfies at least one of these criteria:

1. Raised a Series A round or beyond after YC.
2. Was acquired at a disclosed valuation.
3. Remained in active operation with measurable growth beyond three years after its YC batch.

Approximately 45% of the curated dataset is labeled successful. For recent cohorts, the third criterion may not yet be evaluable, so right-censoring and uneven outcome maturation are important limitations.

Do **not** substitute a funding-round threshold or arbitrary funding amount for this published target definition when claiming to reproduce the paper.

## Data and Reproducibility Notes

Some variables are temporally evolving. In particular, cumulative funding, funding-round count, and Tier-1 investor participation may contain post-incubation information and overlap conceptually with the outcome definition. The published study therefore uses a retrospective classification framing rather than claiming strict application-time forecasting.

For exact numerical reproduction of the paper, the same underlying source records, preprocessing decisions, feature construction, train/test split, tuning procedure, and model-selection procedure are required.
